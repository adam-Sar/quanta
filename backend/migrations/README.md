# Database migrations

Alembic is configured against `app.db.base.Base.metadata` and reads `DATABASE_URL` from the same typed settings as the API.

Task 1 contains a no-domain-table `0001_foundation` revision. It gives every environment a concrete Alembic head and avoids repeatedly initializing/removing the version table before domain tables exist. Task 2 will add the first schema-changing revision together with `datasets` and `dataset_versions`. Generate revisions only after importing all model modules into the metadata path, inspect every autogenerated operation, then run:

```bash
alembic upgrade head
```

Never place credentials in `alembic.ini`.
